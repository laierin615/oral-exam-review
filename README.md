# 測驗評量期中口試特訓

國小教育測驗與學習評量期中口試的複習網頁，手機與電腦都能用。

線上使用：https://laierin615.github.io/oral-exam-review/

## 功能

- **重點背誦**：15 個理論主題，各有口試開場句、圖解、重點與易錯提醒。
  - 背誦模式會遮住答案，先自己講，再點開對答案；可標記「我背熟了」追蹤進度。
  - 使用裝置內建語音朗讀，可單一主題或連續播放全部。
- **口試練習**：46 題申論與情境題，依核心關鍵字估計分數，標出漏講的關鍵字並對照滿分範本。

背誦進度與作答草稿只存在使用者自己的瀏覽器。估計分只依字面比對關鍵字與句型，實際給分以老師判斷為準。

## 技術

單一 `index.html`，以 React 18 與 htm 從 CDN 載入，不需建置。
