# 評量部落・口試特訓

國小教育測驗與學習評量期中口試的複習網頁，手機與電腦都能用。

線上使用：https://laierin615.github.io/oral-exam-review/

## 功能

遊戲化介面（原創繪製的村莊與建築），目的是把理論背熟：

- **村莊**：15 個理論主題就是 15 棟建築。
  - 攻擊＝背誦：答案先遮住，自己講完再揭曉並自評；開場句、全部重點、易錯陷阱都講對才拿 3 星，建好建築。
  - 間隔複習：建好的建築過 1、3、7、14 天會受損，再打 3 星修好並升級。
  - 今日任務、金幣、聖水、連續練習天數。
- **圖鑑**：每個主題的口試開場句、圖解、重點與易錯提醒，可用裝置內建語音朗讀。
- **對戰**：46 題口試題，依核心關鍵字估計分數換成星星，標出漏講的關鍵字並對照滿分範本。

背誦進度與作答草稿只存在使用者自己的瀏覽器。估計分只依字面比對關鍵字與句型，實際給分以老師判斷為準。

## 技術

單一 `index.html`，以 React 18 與 htm 從 CDN 載入，不需建置。
