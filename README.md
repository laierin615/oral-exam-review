# 評量筆記・口試特訓

國小教育測驗與學習評量期中口試的複習網站，採社群卡片版面（粗框、方格紙、膠囊標籤）與米白、暖黃、灰綠的暖色配色，手機優先、大字閱讀。

線上使用：https://laierin615.github.io/oral-exam-review/

## 功能

- **進度圓點**：首頁 15 顆圓點一眼看出熟悉程度（灰綠＝已熟悉、陶土粉＝待複習、米白＝尚未完成回想），點圓點直接開該主題。
- **主題閱讀**：原創 SVG 插畫封面、問題導讀與五章目錄。15 個理論主題依章節配色，可搜尋或只看待複習；內含一句話定義卡、圖解、可點選的概念連線、原始課堂重點卡、概念配對與易錯提醒。
- **回想練習**：答案先遮住，自己說完再揭曉並自評。全部說對後，依 1、3、7、14 天安排複習；提早練習不延後日期。未全對的主題加入待複習。
- **口試練習**：46 題，以原有關鍵字、定義句與實例比對提供估計分，保留草稿、計時與範本對照。
- **語音複習**：用裝置內建語音連續播放全部主題、待複習主題、只聽開場句或只聽易錯提醒，可從上次的位置繼續。朗讀時主題卡標出正在念的段落，播放列顯示目前句子。
- **語音聽考**：先念題目，停頓讓你開口說（提示音＋倒數，或手動按「揭曉」），再念答案；主題回想與 46 題口試題都能用。聽考只用來練習，不改變熟悉程度與複習日期。
- **口說作答**：口試練習可用麥克風把說的話轉成文字，停止後自動檢查回答；支援語音辨識的瀏覽器才會出現（iPhone 需開啟聽寫並連網）。
- 播放或收音時螢幕保持亮著；可調語速、聲音與作答時間。
- **自動選自然語音**：優先用 Edge 的自然語音、自己下載的高品質或加強版聲音、Chrome 的 Google 語音，不列入 Eddy 等機械音與粵語。裝置只有基本語音時，朗讀設定會說明怎麼下載「美佳（加強版）」。
- **白天／晚上版**：刊頭右側可切換「自動｜白天｜晚上」，自動時跟隨裝置深淺色。

## 視覺與內容

參考使用者提供的社群卡片圖，只取版面：粗框與實心陰影、方格紙底、膠囊標籤與分頁。配色沿用原本的暖色：白天米白紙配暖黃封面，晚上深墨綠底配芥末黃封面，重點色是灰綠，五章依序為綠、紫、藍、橘、黃。插畫皆為原創 SVG；不包含參考圖的品牌、照片與原文。正文 18～20px，提示至少 16px，手機單欄、桌機分欄，白天與晚上版都可讀。

主題文字、題庫、估分及間隔複習邏輯保持不變；點選概念連線只會展開既有主題說明。

## 進度相容

保留 `exam-review-v2:` 前綴。舊 `village` 的 stage 與 due 接續為熟悉程度及複習日期；舊 `known` 可接續為第一階段。未刪除舊資源、每日紀錄、連續天數及題目最佳紀錄。新回想結果只補上 needsReview 與 lastReview，不清除其他欄位。

進度與草稿只存在原本的瀏覽器；更換網址來源、瀏覽器或裝置不會自動搬移。估計分用於找出漏講內容，實際給分以老師判斷為準。

## 開發與驗證

單一 `index.html`，React 18 與 htm 固定 CDN 版本，不需建置。

```sh
node tests/check.mjs
node tests/progress.mjs
python3 -m http.server 8765
```

在 375×812 手機視窗檢查深淺色、各主題及圖表、配對、回想與口試流程。圖表與對照表可於自己的區域左右滑動，頁面本身不可橫向捲動。測試資料應使用獨立瀏覽器環境，完成後清除。
